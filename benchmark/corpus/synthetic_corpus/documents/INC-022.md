# INC-022 — Near-Miss Report: Incorrect Valve Selected from a Low-Quality Print

| | |
|---|---|
| Report ID | INC-022 |
| Type | Near-miss report |
| Date of event | 2026-05-19 |
| Unit | Unit 2 (synthetic) |
| Injuries | **None** |
| Status | Closed |
| Data class | Synthetic |

## 1. Summary

During preparation for maintenance work, **an incorrect valve was selected from a low-quality
print**. The print in use was a degraded copy on which one valve tag character was not clearly
legible, and the valve identified from it was not the valve intended for the task. The error
was detected before the valve was operated, during a check at the valve itself. No valve was
operated in error, no isolation was compromised and no work proceeded on the basis of the
incorrect selection.

## 2. What happened

The work party identified the isolation valve for the task by reading the tag from a printed
drawing extract. The print had been photocopied several times and one character in the valve
tag was ambiguous between two possible readings. The work party proceeded to the field with the
reading they had taken from the print.

At the valve location a member of the work party compared the tag on the drawing with the tag
physically fixed to the valve and found that they did not match. Work was stopped and the
correct valve was identified.

## 3. Consequences

**No injury occurred.** No valve was operated. No isolation was compromised. The event is
recorded as a near miss.

## 4. Analysis

The print quality was insufficient to resolve the tag character with confidence. The task
method at the time permitted valve identification to be completed from drawing evidence alone,
with no requirement to confirm the identification against the physical tag before operating the
valve. The ambiguity was not flagged at the point of reading; it was found later, in the field,
by a person who happened to check.

No individual is identified in this report, and the investigation made no finding against any
person. The investigation team recorded that the method, not the personnel, permitted the
error to reach the field.

## 5. Control added

**Independent valve-tag verification was added as a control.** Valve identity taken from any
drawing, print, scan or automated text extraction must now be independently verified against
the physical tag at the valve before that valve is operated or relied upon for isolation.
Drawing evidence alone is no longer sufficient to establish valve identity, and a low-confidence
or ambiguous tag reading must be raised rather than resolved by assumption.

## 6. Actions

| # | Action | Type |
|---|---|---|
| 1 | Independent field tag verification added as a mandatory step before operating an identified valve | Control |
| 2 | Withdraw degraded prints from use and reissue from the controlled drawing set | Control |
| 3 | Ambiguous or low-confidence tag readings to be escalated, not resolved by assumption | Control |
